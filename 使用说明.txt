永雏塔菲桌宠 · 自用

启动
  双击 start.bat

用法
  左键拖动：搬家
  左键单击：说话
  左键双击：转圈
  连点几下：先收费警告，再跺脚
  悬停连续约五秒：害羞摸脸（点她、拖动、转圈、菜单等会重新计时）
  待机散步：默认关闭。托盘 → 设置 打开后，闲着 15~30 秒才会自己走走；打开当下不会立刻走
  走到屏幕边缘会跺脚再折返
  右键：说话 / 变小 / 变大 / 退出
  托盘图标：设置、退出
  设置窗口：置顶、待机散步、大小、API Key、动作预览、换装预览、检查更新

动作
  右键 → 说话菜单里还没有动作；动作在托盘图标右键菜单 →「动作展示」，
  或者设置窗口 →「动作预览」里先看效果再点"让小菲做这个"。
  共 11 个：自然待机 / 招手打招呼 / 摇摆舞步 / 鞠躬 / 点头答应 / 摇头拒绝 /
  歪头卖萌 / 张臂转圈软着陆 / 害羞摸脸 / 跺脚 / 开始·停止走动。
  聊天联动：跟小菲说话时，她会根据回复内容自己点头（答应）/摇头（拒绝）/歪头（疑惑）
    - 动作标签由模型在回复里给出（ACTION:nod|shake|tilt|none），没有标签就不做动作。
  说明：
    - 除了走路，其它动作互斥，点新的会立刻打断旧的；点她、拖她也会打断。
    - 摇摆舞步 4.4 秒、鞠躬 2.4 秒、害羞摸脸 3.6 秒；点头 1.4 秒、摇头 1.6 秒、歪头 2.4 秒。
    - 招手/跳舞的手位是手臂 IK 送到目标点的，目标点用 tools/probe-surface.js
      量过模型表面（脸前 z≈2.0~2.6、腰 z≈1.4、裙前 z≈2.2），不会插进脸/头发/裙子；
      两只手之间也留了空隙，不会交叉。
    - 比心 / 伸懒腰 / 原地跳 / 拍手鼓掌已下线（主人觉得不自然/僵硬）。曲线还留在
      renderer/motion.mjs 里，想恢复就在 renderer/actions.mjs 里加回注册条目。
    - 想自己加/改动作：看 docs/UNIMATE.md 最后一节，改完跑 npm test 和
      npm run preview:actions；注意测试里会检查手离身体表面够不够远、双手间距够不够。

换装
  托盘 → 设置 → 换装，在预览窗口里挑选后再穿到桌宠上。
  自带 1883 配色和几套自制服装。

  要穿官方 2.0 / 兔女郎：
  1. 从官方来源拿到模型文件夹（里面有 .pmx 和贴图）
     B站配布：https://www.bilibili.com/video/BV1Bg411J7hy/
     网盘：https://pan.baidu.com/s/10X-YaQ_G0Yh8azP--YSKgA  提取码 1883
     Steam 合集（可能已下架）：DesktopMMD4「永雏塔菲官方模型合集」
  2. 换装菜单点「导入官方 PMX…」，选中那个文件夹
     或把文件夹放到 models/official/v2 或 models/official/bunny

  导入的衣服只放在本机，不会上传。用过请按借物表署名。
